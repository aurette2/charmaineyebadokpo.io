# 🧑‍💼 Charmaine Yebadokpo - Personal Portfolio

Welcome to my personal portfolio website! This project is a showcase of my skills, projects, and professional journey as an aspiring **software architect and researcher** in Artificial Intelligence, Software Engineering, and Data Science.

> Built on the [Personal](https://bootstrapmade.com/personal-free-resume-bootstrap-template/) template by BootstrapMade, with custom content and styling.

## 📌 Project Overview

This portfolio site was developed to present:

- My **educational background**
- **Projects** in machine learning, web and mobile development
- **Internship experiences** in AI, and Software Development
- **Certifications and awards**
- My **CV** and **contact information**

## 🛠️ Technologies Used

- **Frontend**:
  - HTML5 / CSS3
  - **Bootstrap 5**
  - JavaScript (optional animations and interactivity)

- **Design Features**:
  - Fully responsive layout
  - Modern and clean UI
  - Accessible and SEO-friendly structure

## 🚀 Features

- Professional overview in one place
- Smooth navigation between sections: About, Resume, Projects, Contact
- Links to my GitHub, LinkedIn, and downloadable CV
- Can be deployed via GitHub Pages, Netlify, or your own server

## 🔧 Installation & Setup

To run this project locally:

```bash
git clone https://github.com/aurette2/charmaineyebadokpo.io.git
cd charmaineyebadokpo.io
Open index.html in your browser
```
